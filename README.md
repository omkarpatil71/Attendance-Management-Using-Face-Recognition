# Attendance Management System Using Face Recognition

## 📌 Project Overview
This project is an **automated attendance management system** that uses **face recognition technology** to mark attendance accurately and efficiently. It eliminates manual attendance, reduces proxy attendance, and ensures reliability.

## Short Description
- Built an AI-based attendance system for students and faculty, reducing manual tracking time by 90%.
- Implemented KNN algorithm with OpenCV,
- Achieved 95%+ face recognition accuracy in test conditions
---

## 🚀 Features
- Face detection and recognition
- Automatic attendance marking
- Real-time processing
- Secure and accurate system
- User-friendly interface
- Attendance record storage

---

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Flask
- **Face Recognition:** OpenCV, face-recognition
- **Database:** MySQL / SQLite
- **Frontend:** HTML, CSS, Bootstrap
