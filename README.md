# Attendance Management System (Face Recognition)

- Built an AI-based attendance system for students and faculty, reducing manual tracking time by 90%.
- Implemented KNN algorithm with OpenCV,
- Achieved 95%+ face recognition accuracy in test conditions.
A face recognition-based attendance system using Python, Flask, OpenCV, and MySQL with Power BI dashboard integration.

## Features
- Face recognition
- Automated attendance
- Power BI live dashboard
- Secure login system

## Tech Stack
- Python
- Flask
- OpenCV
- MySQL
- Power BI

## How to Run
1. Clone the repo
2. Install requirements
3. Run app.py
